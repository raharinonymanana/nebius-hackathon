# docs/

Project records, kept as written during the build (dated, newest last).

- `DECISIONS.md` — the decision log: every architecture/scope choice with its date and reason.
  Entries are "not final" unless marked final; later entries supersede earlier ones.
- `LOG.md` — the build log: what was done each session and why.
- `FEEDBACK.md` — friction found while building on Nebius Token Factory, ConTree sandboxes,
  Nemotron and Tavily (the source of the hackathon tool-feedback submission).

How the harness is tested lives in `../TESTING.md`; how to report a security issue in `../SECURITY.md`.
